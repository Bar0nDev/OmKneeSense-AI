# OmkneeSense AI

OmkneeSense AI is a computer vision system designed to estimate **knee joint angles from Visuotactile Sensor (VTS) video data**. The project integrates **video preprocessing, dataset generation, pose estimation, and deep learning-based regression** to predict knee angles from temporal video sequences.

The long-term goal of the system is to provide a **non-invasive biomechanical measurement tool** capable of estimating knee motion using visual sensing technologies.

# Project Components

## kneeAngle

This directory contains all components related to **knee angle estimation**, including:

* dataset generation
* preprocessing pipelines
* machine learning models
* evaluation tools

### kneeAngle/dataGathering

Contains the scripts responsible for **collecting and generating training data**.

#### ultimateDataGathering.py

This script is the **main dataset generation pipeline**. It captures synchronized data streams and processes them into training-ready data.

Core functionality includes:

* VTS video capture
* fisheye distortion correction
* motion magnification
* frame extraction
* density-based pose marker estimation
* knee angle calculation
* dataset export

All generated data is stored in the `output/` directory.

---

#### jointEditor.py

A manual editing tool used to **adjust joint marker locations** generated by the automatic pose estimation pipeline.

This allows manual correction when the density-based joint estimation produces imperfect results.

---

### dataGathering/output

Stores **all recorded sessions and processed datasets**. Each recording session is automatically timestamped.

#### knee/

Contains knee camera recordings and processed frames.

Example session structure:

```
knee_20260227_172031/
    video.mp4
    annotated_video.mp4
    frames/
        raw/
        annotated/
```

* `raw/` – extracted frames from the original video
* `annotated/` – frames with knee angle overlays

---

#### outputCSV/

Stores CSV files containing **frame-by-frame knee angle measurements**.

Example file:

```
knee_angle_tracked_20260227_172031.csv
```

Each row corresponds to a specific video frame:

* row 0 → frame 0
* row 1 → frame 1
* etc.

---

#### vts/

Stores **Visuotactile Sensor recordings** and processed versions.

Example session structure:

```
vts_20260227_172031/
    vts_raw.mp4

    frames/
```

* `vts_raw` – original sensor recording
* `processedVer` – video after preprocessing (motion magnification, fisheye correction, cropping)
* `frames` – extracted frames used for training

# Video Preprocessing Pipeline

The preprocessing system enhances subtle motion signals in VTS recordings.

The method used is **Eulerian Video Motion Magnification**, which is a **classical signal processing technique rather than a machine learning method**.

Processing pipeline:

1. Load video frames
2. Correct fisheye distortion
3. Crop and downscale frames
4. Convert frames to YUV color space (processing brightness channel only)
5. Construct Laplacian pyramids to separate spatial frequencies
6. Apply temporal bandpass filtering (0.8–2.0 Hz)
7. Amplify motion (amplification factor = 30)
8. Reconstruct frames
9. Save processed video output

# Machine Learning Model

## Model Type

CNN-based **temporal regression model** using a modified **ResNet18 backbone**.

---

## Model Architecture

The model processes **temporal sequences of video frames** rather than individual images.

A sequence of frames is stacked along the channel dimension before being passed through the network.

Input representation:

```
9 frames × RGB = 27 channels
```

These stacked frames are fed into a modified ResNet18 where the **first convolutional layer is adapted to accept 27 channels** instead of the standard 3.

The network learns **spatiotemporal visual features** from the frame sequence and outputs a continuous knee angle value.

---

## Model Specifications

Backbone: ResNet18 (pretrained on ImageNet)

Input resolution: 224 × 224

Input channels: 27

Temporal window: 9 frames

Output: 1 continuous knee angle value

Task: pose-based angle regression

Loss function: SmoothL1Loss (Huber Loss)

Optimizer: Adam

Learning rate scheduler: ReduceLROnPlateau

---

# Training Objective

The model is trained to **predict knee joint angles from visual data** using ground-truth angle annotations stored in CSV files.

The regression objective minimizes **Smooth L1 (Huber) loss**, which combines the stability of L2 loss for small errors with the robustness of L1 loss for larger deviations.
